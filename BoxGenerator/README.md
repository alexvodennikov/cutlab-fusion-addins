# BoxGenerator — короба на Lamello Cabineo 8 для Fusion 360

По брифу `../BoxGenerator_brief.md` (заказ Rasmusson, но плагин
переиспользуемый). Структура — по образцу CabinetGenerator.

## Запуск

Папка засимлинкована в `~/Library/Application Support/Autodesk/Autodesk
Fusion 360/API/AddIns/BoxGenerator`. Fusion → Utilities → ADD-INS →
BoxGenerator → Run. Кнопка **«Генератор коробов (Cabineo)»** в SOLID → Create.

## Что делает

Пять панелей (верх, низ, две боковины, врезной задник заподлицо), каждая —
отдельный компонент под нест. В сводке диалога: ведомость, число Cabineo,
кромка передних торцов, площадь.

- **Углы**: «Прямые детали + Cabineo» (схема A — верх/низ во всю ширину;
  схема B — боковины во всю высоту) или **«Шип-паз»** — взаимная гребёнка
  как в CabinetGenerator (пальцы по глубине, пилоты Ø3 под шурупы сквозь
  пальцы горизонтов; Cabineo на углы при этом не ставится).
- **Cabineo 8**: включается отдельно для угловых швов и для задника; на
  каждый шов — количество (0 = авто по шагу, шаг ≤300, отступ от углов
  задаётся, по умолчанию 50). **Шляпки наружу или внутрь** — меняется
  сторона фрезеровки карманов и, соответственно, позиции пилотов.
- **Съёмный задник**: задник без крепежа + четыре упора (пластина
  length×width×t, приложенная пластью к заднему торцу панели, свисает в
  проём); в передней пласти упора гнездо магнита Ø(d+0.3)×(t+0.5), ответное
  гнездо в задней пласти задника; два сквозных пилота Ø4 в упоре под
  саморезы с тыла в торец панели. Задник вынимается только вперёд.

## Фрезеровка Cabineo 8 — первоисточник

Официальный лист Lamello «Cabineo 02/24, Art.No. 986320VS»
(`../Lamello_Cabineo_machining.pdf`), вариант **Bund aufliegend**
(шляпка на поверхности), **фреза ≥Ø10**:

- карман: три окружности **Ø15, глубина 11.0**, центры на **3.6 / 14.8 /
  26.0 мм** от кромки примыкания (шаг 11.2); первая окружность открыта
  в торец (выходит на кромку на 3.9 мм); габарит контура 33.5×15;
- пилот в ответной детали: **Ø5**, ось на **5 мм** от карманной пласти
  примыкающей детали (на листе «5 mm» / «D−5»), глубина **X = 8 мм** от
  плоскости стыка (это «8» в имени Cabineo 8; у Cabineo 12 X = 12).
  До 01.10.2026 плагин ставил ось на 8 мм — ошибка чтения листа, ответные
  отверстия уходили на 3 мм внутрь (короба Rasmusson исправлены вручную);
- панель с карманом ≥12 мм, панель с пилотом ≥16 мм (плагин предупреждает);
  шаг коннекторов ≤300, от угла ≥20.

Реконструкция «20.4×13.2 от кромки 9» из клиентского файла не используется —
дважды бракована при осмотре сборщиком.

## Проверено

Три тестовых короба построены через MCP (Rasmusson №3, №4 со съёмным
задником, вариант с гребёнкой), геометрия карманов/пилотов подтверждена
точечными пробами тел: 15/15 (глубины, открытость кармана в торец, позиции
осей 8 мм, отсутствие лишних отверстий).

## Осталось руками

- Dogbones в углах гребёнки и, при необходимости, в карманах — как обычно,
  отдельным проходом (Dogbone-аддон).
- Раскрой/нест и фактическая сверка первой посадки Cabineo по железу.
